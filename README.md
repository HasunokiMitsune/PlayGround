## Pocket Sprout

A cosy, DS-inspired creature care game that runs entirely in the browser. Warm a mystery egg, name the little Mossling that hatches, and look after it through snacks, games, baths, naps, and training. Care style and time shape its final form.

### Play

Open `index.html` directly, or serve the folder with any static file server:

```sh
python3 -m http.server 3000
```

Then visit `http://localhost:3000`.

### Controls

- **Tap / click** the creature to pet it, or the egg to warm it.
- **F** snack · **P** play · **B** bath · **N** nap / wake · **T** train
- **D** diary · **H** help · **M** mute · **W** warm the egg
- All input also works with touch and pointer controls.

Progress saves automatically to `localStorage` under `pocket-sprout.v1`. The game uses bundled Nunito webfonts (SIL Open Font License, see `fonts/OFL.txt`) and procedural canvas art — no external assets or frameworks.
